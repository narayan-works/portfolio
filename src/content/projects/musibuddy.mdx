    <p>MusicBuddy is an attempt to build a machine with "aesthetic intelligence." Inspired by Gordon Pask's MusiColour (1953), this prototype deconstructs audio into deep structural data (Tatums, Beats, Bars) to create a feedback loop where the machine doesn't just display the music, but "performs" it—getting bored if the song is too repetitive, or overwhelmed if it's too complex.</p>
