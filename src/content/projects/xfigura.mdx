    <h2 class="left-align core-section-title">The Core UI Elements &amp; Interactions</h2>
    <p class="left-align core-section-desc">The text-to-node interface relies on three core UI components that work together across the layout canvas:</p>

    <div class="xf-grid grid-3">
        <article class="core-card">
            <h3 class="core-card-title">Source Text Node</h3>
            <p class="core-card-desc">The entry point on the left of the canvas where you type the prompt. It tokenizes terms like <code>/visualization</code>, <code>/deep</code>, and <code>/rotate</code> into active pills. Clicking Parametricize kicks off the graph generation.</p>
        </article>

        <article class="core-card">
            <h3 class="core-card-title">Decoupled Parameter Sliders</h3>
            <p class="core-card-desc">Independent control cards that spawn on the canvas with clear 20px vertical spacing. They map the parsed variables into manual controls with direct numeric readouts (20 mm, 44°, 70%, 5').</p>
        </article>

        <article class="core-card">
            <h3 class="core-card-title">Main Generation Hub</h3>
            <p class="core-card-desc">The central parent card positioned in the middle of the workspace. It features visual input sockets on the left edge to receive data wires from the parameter sliders, a reference image dropzone, and a Generate Visualization button at the base to render the final preview node.</p>
        </article>
    </div>
