<ProjectSection title="Headless Notion CMS Architecture" id="architecture">
    <p>
        Rather than building a heavy traditional CMS or requiring non-technical editors to modify React code, the website operates as a "headless" front-end querying Notion as the single source of truth.
    </p>
    <p>
        The Next.js application securely pulls down page blocks and database properties using the Notion Client SDK. A recursive block-to-component translator (<code>BlockRenderer</code>) parses raw Notion layout blocks—such as lists, columns, callouts, and images—and maps them to fully stylized, responsive Tailwind CSS React components in real time.
    </p>
</ProjectSection>

<ProjectSection title="The Collaboration & Matching System" id="matching">
    <p>
        To foster academic and practice collaboration, the platform implements a dynamic matchmaking system. Scholars and students submit applications identifying their organizations, keywords, and interests.
    </p>
    <p>
        Submissions are handled strictly on the server using Next.js <strong>Server Actions</strong>, which securely format the data and push new entries directly into the Matching Notion database. The system handles secure session management and authentication using a custom email OTP (One-Time Passcode) verification flow powered by Nodemailer.
    </p>
</ProjectSection>
