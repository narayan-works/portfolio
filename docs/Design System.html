Portfolio Design System

A directory of the core design tokens, typography scales, layout spacings, and bento components powering Narayan's portfolio. Encoded in global.css and styled using semantic Custom Properties.

Color Palette

The color palette leverages CSS Custom Properties mapped to specific roles. The layout automatically swaps colors on light mode by setting the [data-theme="light"] selector.
